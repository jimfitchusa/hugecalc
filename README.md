# HUGECALC
HugeCalc: Arbitrary-Precision Scientific Calculator

1991: Typing Neil Rubenking's original Turbo Pascal code by hand from the September issue of PC Magazine.

1991-2000: Porting the string-math engine to C to keep it alive.

2025-2026: Modernizing the engine in Python, restoring the exact integer logic, and expanding it to support Maclaurin series, continuous complex mathematics, and Newton-Raphson root solvers out to 40 digits of precision.
